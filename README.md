# AI Startup School — Telegram Mini App

Mobile-first prototype for the AI Startup School Telegram Mini App.

## Screens
- Home
- Learning
- Project
- AI mentor
- Profile

## Local run
```bash
npm install
npm run dev
```

## Telegram bot
Copy `.env.example` to `.env`, set `BOT_TOKEN` and the HTTPS `MINI_APP_URL`, then run:

```bash
npm run bot
```

Never commit the bot token or API keys.
