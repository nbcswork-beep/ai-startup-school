# Сайты, код и статьи на сайтах учеников

Шесть адаптированных навыков включены в стандартный каталог агента: создание сайтов, дизайн/анимации, разработка, диагностика, проверка кода и SEO-статьи. Исходные инструкции Addy Osmani и MengTo, их Git blob SHA и MIT-лицензии сохранены в upstream/ и sources.json. SEO-правила дополнительно основаны на Google Search Central:

- https://developers.google.com/search/docs/fundamentals/creating-helpful-content
- https://developers.google.com/search/docs/appearance/title-link

Это инструкции для существующей модели, а не её обучение. Нет Composio/Nango SDK, платного подписочного API или дополнительных ключей. Расходуются токены настроенного провайдера и ресурсы текущего хостинга/Redis.

## Рабочий сценарий

1. Включить «Агент», попросить создать сайт. Навык выбирается автоматически или вручную.
2. Агент вызывает create_project с полными файлами. В чате появляются ZIP и «Переглянути сайт».
3. Попросить добавить статью. read_project читает существующий сайт; create_project с projectId обновляет черновик вместе с блогом и навигацией.
4. Попросить «Опубликуй сайт». publish_project ждёт подтверждения ученика. После подтверждения возвращается стабильный публичный URL /api/v1/sites/{projectId}/index.html. Статьи доступны по своим HTML-путям.
5. Из предпросмотра можно открыть опубликованный сайт или снять его с публикации. Черновик остаётся доступен владельцу.

Черновые изменения не заменяют опубликованную версию. Подписанный приватный просмотр и ссылки скачивания действуют 10 минут, опубликованные страницы — до снятия с публикации. Публичные страницы не содержат имя ученика автоматически. Владелец обязан исключить личные данные из публикуемых материалов.

## Границы возможностей

- 60 текстовых файлов, до 300 КБ исходного текста на проект, 6 файлов/проектов за запуск агента.
- Публикуются статические HTML/CSS/JS сайты. Поддерживаются несколько страниц, SVG, CSS-анимации, браузерная интерактивность. Корневые URL вида /style.css запрещены: нужны относительные пути, включая ../styles.css из блога.
- JS работает в изоляции без доступа к сессии школы, localStorage, fetch, формам и внешним JS CDN. Сервер никогда не запускает сгенерированные программы. JS-модули и пользовательские сценарии браузера не проверяются структурным анализом.
- React/Node/Python и другой код выдаются как исходный ZIP с README; сборка, выполнение, серверная авторизация и платежи здесь не предоставляются.
- Публикация в сторонний WordPress/Webflow/хостинг не подключена. Ранжирование, индексация и SEO-трафик не гарантируются.
- При включённой долговременной памяти старый projectId может выпасть из контекста после сжатия; его можно передать из карточки проекта. Список файлов текущей истории содержит projectId.

## Проверка

server/ai-projects.unit.test.ts проверяет ZIP, ресурсы и HTML-ссылки, запрет опасных путей, права владельца, подписанный предпросмотр, изолирующие HTTP-заголовки, сохранение опубликованной версии при редактировании и снятие с публикации. Агент использует существующий механизм подтверждения действий с разрешением network. Модельные ответы проверяются с тестовым провайдером; это не оценка качества реальной модели.

Пользовательские изменения существующих встроенных навыков сохраняются. Новые навыки добавляются автоматически по постоянным id. Находящиеся в Redis уроки, ученики и лимиты не мигрируются этим обновлением.
