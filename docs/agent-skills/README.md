# Навыки документов для Student OS

Подготовлено 2026-10-15. Источник: https://github.com/xcrrr/claude-skills, skills/files/{pptx,docx,pdf,xlsx}, лицензия MIT, Copyright (c) 2026 Adam Parszewski.
Оригиналы находятся в upstream/, контрольные Git blob SHA — в upstream/sources.json. Лицензия сохранена в LICENSE и в адаптированных инструкциях.

## Что подключено

- Презентація: существующий skill-slides дополнен методикой выбора сюжета, заголовков, заметок и выступления.
- Документи Word: новый skill-docx-github.
- PDF: читання та оформлення: новый skill-pdf-github.
- Таблиці Excel: новый skill-xlsx-github.

Встроенные инструкции подключены через server/ai/agent/skills.ts и community-document-skills.ts. Это адаптация инструкций, а не установка внешнего исполняемого кода. Работает с текущей моделью и инструментами read_file/create_file; calculate используется только если доступен.

## Применение на действующем сайте без публикации кода

В административной панели откройте раздел агента, блок «Навички», кнопку «Імпорт SKILL.md». Выберите четыре адаптированных .md файла из архива (предварительно распакуйте его). Сам ZIP форма не принимает.
Импорт заменяет навык с совпадающим именем. Перед заменой «Презентація» экспортируйте его, если там есть ваши собственные изменения. Остальные настройки, плагины и модели не меняются.
После импорта проверьте, что навыки включены. Сохранённые отключённые навыки импорт сам не включает — включите их в панели.
Не импортируйте upstream/: оригиналы содержат инструкции для инструментов, которых у приложения нет.

## Поведение после публикации локальных изменений

Новые встроенные навыки доступны по умолчанию. Уже сохранённые в хранилище настройки навыков имеют приоритет: их текст и состояние включения не перезаписываются. Для обновления изменённой ранее «Презентація» нужен импорт адаптированного файла либо осознанный сброс этой навички.
Код не подключает GitHub при каждом запросе: версии зафиксированы локально, обновления требуют проверки.

## Границы возможностей

PPTX: статичные слайды 16:9 с существующим оформлением. Анимации — только явно помеченные рекомендации в заметках, не эффекты в файле.
Word: создание нового DOCX с заголовками, списками и таблицами; не редактирование оригинала с сохранением верстки и правок.
PDF: чтение доступного текста и создание документа A4; не точная конвертация, OCR или экспорт слайдов.
Excel: аркуши, таблицы и статические значения; не исполняемые формулы, графики, сводные таблицы или автоматический пересчёт.
Визуальный просмотр файла агенту не добавлен. Структурную проверку нельзя выдавать за визуальную.
