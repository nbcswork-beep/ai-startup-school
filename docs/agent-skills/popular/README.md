# Три навыка для школьного агента

Подготовлено 15 октября 2026 года. Это адаптированные инструкции для существующего агента Student OS.

## Что входит
1. Презентація: обновление существующего навыка на основе Scientific Slides (K-Dense). Сценарий, понятные слайды, корректные данные, заметки для выступления и самопроверка.
2. Критичне мислення: проверка аргументов, источников, причинных связей и чисел на основе Scientific Critical Thinking (K-Dense).
3. Навчальні тексти та джерела: план, черновик и редактура с проверяемыми основаниями на основе Content Research Writer (Composio).

## Импорт на работающий сайт
1. Распакуйте архив.
2. В админке откройте «Агент» → «Навички». Если меняли навык «Презентація», сначала экспортируйте его как резервную копию.
3. Нажмите «Імпорт SKILL.md» и выберите ТОЛЬКО три файла из папки import. ZIP целиком форма не принимает.
4. После импорта убедитесь, что все три навыка включены. Существующие отключённые навыки импорт автоматически не включает.
5. В чате включите «Агент». Можно выбрать навык явно или позволить агенту найти подходящий по описанию.

Импорт заменит одноимённые навыки, остальные не затронет. При первом импорте на исходную версию сайта добавятся два навыка и обновится «Презентація». При повторном импорте обновятся все три.

## Примеры проверки
- Презентація: «Зроби 8 слайдів про основи бізнесу для учнів 14 років. Навчальні приклади познач. Додай нотатки для виступу на 4 хвилини».
- Критичне мислення: «Пʼять друзів спробували застосунок і всім сподобалось. Отже, його купуватимуть усі школярі. Перевір цей висновок і запропонуй кращий спосіб перевірки».
- Навчальні тексти та джерела: «Допоможи покращити мою чернетку: скороти повтори, перевір аргументи і покажи 3 найважливіші правки». Додайте свою чернетку.

## Что уже может агент
Статичный PPTX 16:9 с текущим оформлением, Markdown-структура слайдов и заметки; чтение прикреплений; документы Word/PDF; анализ текста; calculate, если калькулятор включён.
Переобучение модели и смена провайдера не требуются.

## Что требует расширения инструментов
Произвольные макеты, картинки, графики, настоящие анимации, визуальный просмотр и исправление рендера, полноценный вебпоиск. Эти возможности в пакет не добавлены. Исходные скрипты Scientific Slides не установлены и не запускаются.
Навык не должен обещать их наличие. Рекомендации анимации в заметках нужно применять вручную.

## Локальная интеграция
Навыки зарегистрированы в server/ai/agent/skills.ts, тексты — в school-research-skills.ts.
Существующие тексты и состояние навыков в хранилище имеют приоритет над локальными значениями по умолчанию. Публикация исходников сама по себе не перезаписывает настройки администратора; для обновления сохранённых навыков предназначен импорт.
Сайт через браузер не изменён. Ранее доступ к административной странице был отклонён; обход этого ограничения не использовался.
